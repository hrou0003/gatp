# Lecture 04: Topological Spaces — Construction and Purpose (Review)

## Definition

A **topology** on M is 𝒪 ⊆ 𝒫(M) with:
1. ∅, M ∈ 𝒪
2. U, V ∈ 𝒪 ⇒ U ∩ V ∈ 𝒪 (finite intersections)
3. C ⊆ 𝒪 ⇒ ⋃ C ∈ 𝒪 (arbitrary unions)

(M, 𝒪) is a **topological space**.

## Key examples

| Topology | Definition |
|----------|-----------|
| Chaotic (coarsest) | {∅, M} |
| Discrete (finest) | 𝒫(M) |
| Standard on ℝᵈ | U ∈ 𝒪 :⇔ ∀p ∈ U : ∃r > 0 : B_r(p) ⊆ U |

**Coarser/finer:** 𝒪₁ ⊂ 𝒪₂ means 𝒪₁ is coarser (weaker).

**Open** if S ∈ 𝒪. **Closed** if M\S ∈ 𝒪. ∅ and M are both. A set can be neither, both, or just one.

## New topologies from old

- **Induced (subset):** N ⊂ M, 𝒪|_N := {U ∩ N | U ∈ 𝒪}
- **Quotient:** M/∼ with q: M → M/∼, 𝒪_{M/∼} := {U | preim_q(U) ∈ 𝒪}
- **Product:** 𝒪_{A×B} generated by {S × T | S ∈ 𝒪_A, T ∈ 𝒪_B}

## Convergence

q: ℕ → M converges to a if ∀U ∈ 𝒪 : a ∈ U ⇒ ∃N : ∀n > N : q(n) ∈ U.

- Chaotic: every sequence converges to every point
- Discrete: only eventually constant sequences converge
- Standard on ℝᵈ: usual ε-δ convergence

## Continuity

φ: M → N is **continuous** if pre-images of open sets are open: preim_φ(S) ∈ 𝒪_M for all S ∈ 𝒪_N.

**Homeomorphism:** bijection where both φ and φ⁻¹ are continuous. (M, 𝒪_M) ≅_top (N, 𝒪_N).
