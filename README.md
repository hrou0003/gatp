## Course arc

```
Lectures 01       Propositional logic (language of mathematics)
         02–05    Topology (the bare minimum structure for continuity)
         06–07    Smooth manifolds (where we can do calculus)
         08–11    Tangent/cotangent bundles (infinitesimal structure)
         12–13    Tensor fields and differential forms
         14–17    De Rham cohomology (topology meets calculus)
         18–19    Lie groups and algebras (symmetry)
         20–25    Fiber bundles, connections, curvature (gauge theory)
```
